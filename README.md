# Library Management System

## Project Description
A console-based Library Management System built in Python. It allows a librarian to manage books and members, and lets members borrow and return books. All data is saved permanently using JSON files.

## Features
- Add new books to the catalogue
- View all books with availability status
- Register new library members
- View all registered members
- Borrow a book (with validation)
- Return a book
- Data saved automatically to JSON files

## Technologies Used
- Python 3
- JSON (built-in) for storage
- os, datetime modules

## Python Concepts Used
- Variables, Data Types, Operators
- Conditional Statements, Loops
- Functions
- Data Structures (list, dict)
- File Handling
- Exception Handling
- OOP: Classes, Objects, Constructors, Inheritance, Polymorphism, Encapsulation
